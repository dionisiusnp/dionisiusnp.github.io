// cheat.commands

Developer Cheat Sheet

Command siap pakai per kategori — setup di kiri, jalankan project di kanan.

🐘 Laravel PHP Framework
// setup & install
composer install
Install semua PHP dependencies dari composer.json
cp .env.example .env
Buat file environment dari template
php artisan key:generate
Generate app key di .env
php artisan migrate
Jalankan semua migration database
php artisan make:model Nama -mcr
Buat Model + Migration + Controller + Resource sekaligus
composer require nama/package
Tambah package baru via Composer
// running project
php artisan serve
Jalankan dev server di localhost:8000
php artisan migrate:fresh --seed
Reset DB dan isi ulang dengan seeder
php artisan route:list
Tampilkan semua route yang terdaftar
php artisan queue:work
Jalankan background job queue worker
php artisan tinker
Interactive REPL untuk test query Eloquent
npm run dev
Compile frontend assets (Vite/Mix) dalam mode dev
🐦 Flutter Dart · Cross-platform
// setup & install
flutter create nama_app
Buat project Flutter baru
flutter pub get
Install semua dependencies dari pubspec.yaml
flutter pub add nama_package
Tambah package baru ke pubspec.yaml
flutter doctor
Cek status instalasi Flutter dan dependencies
flutter clean
Bersihkan build cache — pakai kalau ada error aneh
// running project
flutter run
Jalankan ke device/emulator yang terdeteksi
flutter run -d chrome
Jalankan di browser Chrome (mode web)
flutter devices
Tampilkan semua device yang terhubung
flutter build apk --release
Build APK Android siap rilis
flutter test
Jalankan semua unit dan widget test
☕ Java JDK · Maven · Gradle
// setup & compile
javac NamaFile.java
Kompilasi file Java menjadi bytecode .class
jar cf app.jar *.class
Buat JAR dari file .class yang sudah dikompilasi
mvn clean install
Build project Maven dari awal + install ke local repo
gradle build
Build project Gradle
mvn test
Jalankan unit test dengan Maven
// running project
java NamaClass
Jalankan program Java dari class yang sudah dikompilasi
java -jar app.jar
Jalankan aplikasi dari file JAR
java -cp . NamaClass
Jalankan dengan classpath direktori saat ini
mvn exec:java -Dexec.mainClass="App"
Jalankan class main lewat Maven tanpa build JAR dulu
gradle run
Jalankan aplikasi lewat Gradle
🍃 Spring Boot Java Framework
// setup & anotasi
@SpringBootApplication
Anotasi utama di class main — entry point aplikasi
@Entity @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
Definisi entity JPA dengan auto-increment ID
@RestController @RequestMapping("/api/nama")
Definisi REST controller dengan base URL
spring.datasource.url=jdbc:mysql://localhost:3306/dbname spring.datasource.username=root spring.datasource.password= spring.jpa.hibernate.ddl-auto=update
Konfigurasi koneksi MySQL di application.properties
@ControllerAdvice @ExceptionHandler(Exception.class)
Global error handler untuk semua controller
// running project
mvn spring-boot:run
Jalankan Spring Boot via Maven (paling umum)
gradle bootRun
Jalankan Spring Boot via Gradle
mvn clean package java -jar target/app-0.0.1.jar
Build JAR lalu jalankan langsung — cara deploy production
@GetMapping("/health") public String health() { return "OK"; }
Endpoint health check — cek server running di localhost:8080
mvn test
Jalankan semua unit test Spring
🐳 Docker Container · Compose
// setup & build
docker build -t nama:tag .
Build image dari Dockerfile di direktori saat ini
docker pull nama:tag
Download image dari Docker Hub
docker images
Tampilkan semua image yang tersimpan lokal
docker rmi nama:tag
Hapus image dari lokal
docker system prune -a
Bersihkan semua resource Docker yang tidak terpakai
// running project
docker compose up -d
Jalankan semua container dari docker-compose.yml di background
docker compose down
Stop dan hapus semua container yang sedang berjalan
docker compose logs -f
Lihat log real-time dari semua container
docker ps -a
Lihat semua container termasuk yang stopped
docker exec -it <id> bash
Masuk terminal interaktif di dalam container
🌿 Git Version Control
// setup & repo
git init
Inisialisasi repository Git baru di folder saat ini
git clone <url>
Clone repository remote ke lokal
git remote add origin <url>
Hubungkan repo lokal ke remote GitHub/GitLab
git status
Lihat status file — mana yang berubah, staged, atau untracked
git log --oneline
Lihat riwayat commit dalam satu baris per commit
git diff
Lihat perubahan file yang belum di-stage
git stash
Simpan sementara perubahan yang belum siap di-commit
git stash pop
Kembalikan perubahan yang di-stash ke working directory
// commit & branch
git add .
Stage semua perubahan untuk commit
git commit -m "pesan"
Commit perubahan yang sudah di-stage dengan pesan
git push origin main
Push commit lokal ke branch main di remote
git pull origin main
Tarik perubahan terbaru dari remote ke lokal
git checkout -b nama-branch
Buat branch baru sekaligus pindah ke sana
git merge nama-branch
Gabungkan branch ke branch yang aktif saat ini
git branch -d nama-branch
Hapus branch lokal yang sudah tidak diperlukan
git reset --soft HEAD~1
Batalkan commit terakhir, perubahan tetap ada di staging
